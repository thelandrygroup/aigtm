# ClearCo Overlay

Apply the top-level `CLEARCO.md` before using this skill.

For ClearCo messaging, lead with persona, pain, and business impact before naming features. Use the lifecycle model: Hire, Succeed, Grow, and Platform.

Messaging should make ClearCo feel like a connected talent operating layer, not a generic ATS or point solution.

Separate positioning, value propositions, proof, objections, and missing evidence. Use public or user-provided proof only.

Do not invent ROI, implementation timelines, AI claims, compliance guarantees, customer outcomes, or private competitive claims.
