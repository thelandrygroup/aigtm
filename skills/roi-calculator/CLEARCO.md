# ClearCo Overlay

Apply the top-level `CLEARCO.md` before using this skill.

For ClearCo-related work, frame the output around buyer-confirmed business impact and the relevant lifecycle area: Hire, Succeed, Grow, or Platform.

Separate verified inputs, assumptions, hypotheses, and recommended next questions. If a metric is not provided by the user or a trusted public source, mark it as an assumption and ask for validation.

Do not invent ROI, time savings, implementation timing, AI accuracy, compliance guarantees, or customer outcomes. Keep private customer data, pricing, pipeline context, transcripts, and security material out of repo files and externally shared drafts.
